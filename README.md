# 選戰風雲S

手機可直接開啟公開網址。 [選戰風雲S 網頁試玩](https://tongxiaooppo-boop.github.io/fightgame-duel-playtest/)

Chrome 可從右上角選單安裝遊戲。選角或暫停時，也能用頁面右上角的「全螢幕」切換。安裝版以橫向全螢幕為預設，需要網路下載遊戲。對戰中切到背景或轉回直向會暫停，回到橫向後點「繼續」。

開局選「1 對 1」或「闖關模式」，再選場地和角色。1 對 1 與 CPU 打一場，先贏兩回合的一方獲勝，可重賽。滿槽練習會切到 1 對 1。

闖關模式用同一位角色一路打八關。每關先贏兩回合才能晉級，落敗可重打本關。CPU 逐關加快走位與出招，中段開始看起手格擋，後段會拉開距離、抓揮空或收招的破綻反擊，也會接必殺與大絕。最後在造勢大會打贏洪萬金，就會看到所選角色的專屬結局。

鍵盤按 **1／2** 選模式、方向鍵選角、**G** 換場地、**Enter／空白鍵**開打或接下一關。每回合 60 秒。

用 **A／D** 或 **←／→** 移動，按 **W／↑** 跳躍，在地面按住 **S／↓** 防禦正面攻擊。**J** 近身出拳、稍遠出腳。

柳語棠會帶著拜票旗衝上前，把交通政見的幹道和支線打出去，或在擂台上標出「青鳥集合」的落點。顧墨白的「交互詰問」會臨時加開一輪，「請附來源」查核單命中後蓋退件戳，三波留言則依序送出「推」、「+1」和「洗版」。

J 命中後連按可接同套三段。前兩段可轉接距離足夠的必殺或大絕，第三段會擊退對手並結束連段，貼牆也會拉開距離。三個必殺分別計算冷卻，施放時有台灣國語語音和字幕。攻擊命中、受擊和格擋累積大絕槽，滿槽才能按 I。大絕起手命中才播放台詞、特寫與七段攻擊。被防或揮空仍會用掉槽。

電腦試玩時，可按住方向鍵移動，同時用滑鼠點擂台下方的普攻、三個必殺或大絕。冷卻中的按鈕顯示剩餘秒數，大絕槽未滿時大絕按鈕淡化。大絕的收尾會切到蓄力近景、定住最後一擊，再拉回側視看擊飛。

預設 CPU 開局會留時間走位，每次出招後也會留反擊空檔。想馬上試大絕，在選角畫面點「滿槽練習」或按 **F2**，每回合開始時玩家滿槽。鍵盤按 Esc 暫停、M 靜音。暫停後可按 Esc 繼續、R 重打或 Tab 回選角。

橫向觸控用左搖桿移動、上推跳躍。按住搖桿旁的 **防** 或把搖桿向下推，就能在站立且可行動時防禦。成功格擋會出現盾形閃光。右邊是普攻、三個必殺和大絕。Windows 可按 **F1** 顯示觸控版面。

## 本機開發

用 Godot 4.7.2 stable 開啟根目錄的 `project.godot`，按 **F5** 執行。若從命令列操作，先匯入素材，再跑戰鬥規則和場景測試。

```sh
godot --headless --path . --import
godot --headless --path . --script res://2D/tests/duel_test.gd
godot --headless --path . --script res://2D/tests/duel_scene_test.gd
```

安裝同版本的 Web 匯出範本後，從專案根目錄用 PowerShell 執行 `./2D/export-web.ps1`。如果 Godot 未加入 PATH，傳入 `-Godot` 指定執行檔。輸出在 `build/duel-web` 和 `build/duel-web.zip`。

同一個 repo 的 `main` 分支部署 GitHub Pages，`source` 分支放可執行的 2D Godot 原始專案。
